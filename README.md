# Brilliant or Blunder: memories and brand

Everything Claude Code knows about the Brilliant or Blunder YouTube channel (@BrilliantOrBlunderTV): famous movie and TV scenes, graded move by move like a chess game. Exported 15 Oct 2026.

## What is in here

| Path | What it is |
|---|---|
| `memory/brilliant-or-blunder-channel.md` | The full project memory: format study, Checkmate Cinema to Brilliant or Blunder rebrand, EP01 versions v1 to v5, narrator voice picks, EP02 plan, open items. |
| `PROGRESS.txt` | Status snapshot from 12 Oct 2026 with the next steps list. |
| `brand/DESIGN.md` | Design system: colours, type, badges, move cards, thumbnails, motion, voice, never list. Read it before designing anything for the channel. |
| `brand/tokens.css` | Colour and font tokens. |
| `brand/logo/` | Final avatar (SVG + 800x800 PNG), plain mark, banner (2560x1440 JPG + editable HTML). |
| `brand/_src/` | Builders for the avatar and banner (render with headless Chrome) plus the Anton and Inter fonts (both SIL Open Font License). |

## How to use on another machine

Copy `memory/brilliant-or-blunder-channel.md` into the Claude memory folder (`~/.claude/projects/<project>/memory/`) and add a line for it in `MEMORY.md`. Copy `brand/` into `Documents\Design Systems\brilliant-or-blunder`.

File paths inside the notes point to Judah's Windows PC (`C:\Users\User\...`). Update them on a new machine.
